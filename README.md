# Portfolio

A personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## What's inside
- Responsive single-page portfolio layout
- Smooth scrolling navigation
- Sections for home, skills, experience, and contact
- Animated scroll effects and UI components
- Styled with modern CSS and Google Fonts

## Tech stack
- HTML5
- CSS3
- JavaScript
- Font Awesome

## Getting started
```bash
# serve locally
npx serve .
```
